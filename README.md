Pinboxx uses a unique polling mechanism that performs ultra-fast envelope scanning. By bypassing heavy IMAP search indices and focusing on recent message headers, we achieve OTP delivery times that rival real-time push notifications.

## 🔧 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Vrushabh100/pinboxx.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment:**
   Create a `.env` file in the root directory:
   ```env
   GMAIL_EMAIL=your-secure-email@gmail.com
   GMAIL_APP_PASSWORD=your-app-specific-password
   PORT=3000
   ```

4. **Start the Engine:**
   ```bash
   npm start
   ```
